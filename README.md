# 月の満ち欠け

起動.cmd または dist/index.html を開くと使えます。ネット接続・インストールは不要です。

- 月をドラッグ、軌道をタップ、またはスライダーで公転位置を変更
- 宇宙からの位置と地球から見える形が連動
- 自動再生、8つの形の選択、夕方の空、4択クイズ
- 北極側からの模式図。地球からの月は日本で南の空を見る向きに相当する表示です。
- 1周は満ち欠けの周期約29.5日。恒星に対する公転周期とは異なります。
- 太陽・地球・月の距離や大きさ、空の位置は簡略化しています。月軌道の傾きと季節変化は省略しています。

参考資料：ユーザー提供「3年_2_地球_3章.docx」p.83–84、月の公転と満ち欠けの添付図。本文・図版の転載はしていません。

確認：JavaScript構文検査、ローカルHTTP 200、ブラウザー表示、満月の切替、クイズ正解判定。

公開は未実施です。Sitesの候補URLがアカウント名を含むため、公開先の指定条件に合わせて保留しています。


## iPad向けビジュアル更新

縦820×1180・横1180×820のブラウザー表示を確認。横スクロールなし、主要タッチ操作領域44px以上。実機iPad Safariは未確認。
月面は写真ではなく、クレーターと暗い平原を計算で描いたイラストです。球面上の太陽光の角度に応じて明暗を変えています。地球・太陽・地平線も模式的な表現です。
月面の固定形状を事前計算し、再生を約30fpsに抑えて描画負荷を軽減。クイズはモーダル表示で背景の誤操作を防止。
確認：構文検査、iPad相当の縦横表示、満月100%への連動、クイズ表示、横幅のはみ出しなし、操作ボタンの高さ。


## 観察時刻の切り替え

03 同じ時刻の空で「夕方・真夜中・明け方・昼」を選択。月の位置・太陽・空の背景と、01の地球上の観察者が連動します。01の「人の表示」で表示・非表示を切り替えます。非表示のままでも時刻の切り替えは使えます。
北極側から見て、夕方は上、真夜中は左、明け方は下、昼は右。空は日本で南を向いた模式図で、季節・緯度による高度の違いは省略しています。新月の位置は目印で、通常は見えません。
確認：4時刻のブラウザー切り替え、観察者の位置と表示オフ、真夜中の満月が南の高い位置。計算検査で4時刻の南中・東西の地平線・地平線下を確認。


## 科学的な表記の修正

途中の月は「満ちていく月」「欠けていく月」と表示。新月・上弦・満月・下弦は対応する位置に限定しています。「三日月」ボタンは月齢との不一致を避けて「細い月」に変更。
「満ち欠けは約29.5日周期」、月齢は「目安」と表示。空の月は向きをそろえた記号であることを明示し、高度・方位・傾きや観察時刻の予測をしない概念図として扱います。
省略事項はアプリ下部の「この図で省略していること」で確認できます。月面は生成イラストであり、地形図ではありません。
検証：check-phases.cjs（名称と境界の回帰検査）、check-sky.cjs（4時刻と地平線）、JavaScript構文検査、ブラウザーで細い月→上弦→90.1度の表示を確認。
